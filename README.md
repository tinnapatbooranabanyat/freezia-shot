# Freezia

โปรแกรมจับภาพหน้าจอสำหรับ Windows 10/11 (x64) แนวเดียวกับ Lightshot แต่หน้าตาทันสมัยกว่าและแก้ไขภาพได้มากกว่า
เขียนด้วย C# + .NET 10 + WPF ภาพและการตั้งค่าทั้งหมดอยู่ในเครื่องเท่านั้น **ไม่มี cloud ไม่มี telemetry**
การเชื่อมต่ออินเทอร์เน็ตมีอย่างเดียวคือตรวจหาอัปเดตจาก GitHub (ปิดได้ในหน้าตั้งค่า)

> **English:** Freezia is a free, open-source (MIT) screenshot tool for Windows 10/11. Capture a region, window,
> UI element, screen or all monitors, then annotate it in a built-in editor (arrows, shapes, text, steps, blur,
> pixelate, spotlight, crop, resize). It also does Thai/English OCR, QR/barcode reading, pin-to-screen, capture
> history and a screen color picker. Everything runs locally and there is no telemetry; the only network
> access is an update check against GitHub Releases (can be turned off in Settings).
> Downloads: [Releases](https://github.com/tinnapatbooranabanyat/freezia-shot/releases) ·
> [Code signing policy](#code-signing-policy)

## ฟีเจอร์

- **ทำงานเบื้องหลังที่ถาดระบบ (system tray)**: เมนูแคปพื้นที่ / แคปจอนี้ / แคปทุกจอ / เปิดโฟลเดอร์ที่บันทึก / ตั้งค่า / ออก
  - ดับเบิลคลิกไอคอน = แคปพื้นที่
  - เปิดได้ทีละตัว ถ้าเปิดซ้ำตอนที่ทำงานอยู่ จะเปิดหน้าตั้งค่าขึ้นมาแทน
- **ปุ่มลัด** (เปลี่ยนได้ในหน้าตั้งค่า)

  | ปุ่ม | การทำงาน |
  |---|---|
  | `PrintScreen` | แคปพื้นที่ |
  | `Ctrl + PrintScreen` | แคปเต็มจอที่เมาส์อยู่ |
  | `Ctrl + Shift + PrintScreen` | แคปทุกจอรวมเป็นภาพเดียว |

- **โหมดแคปพื้นที่**: ทุกจอหยุดนิ่งและมืดลง ลากเพื่อเลือก (ลากข้ามจอได้) มีแว่นขยายบอกพิกัดและรหัสสี HEX และแสดงขนาด กว้าง × สูง
  - **คลิกเดียวเลือกทั้งหน้าต่าง** และกด Ctrl ค้างไว้เพื่อเลือกส่วนย่อย (ปุ่ม แผง ช่องข้อความ) ผ่าน UI Automation
- **ปักหมุดภาพไว้บนจอ**: ภาพลอยอยู่บนสุดที่ตำแหน่งเดิม ขนาดพิกเซลจริง ย้าย ซูม ปรับความโปร่งใสได้
- **ดึงข้อความจากภาพ (OCR) ภาษาไทย + อังกฤษ** ด้วย Tesseract ทำงานในเครื่องทั้งหมด
- **อ่าน QR code / บาร์โค้ด** ด้วย ZXing.Net
- **ประวัติการแคป**: เก็บภาพล่าสุด (ค่าเริ่มต้น 50 ภาพ ปรับหรือปิดได้) เปิดจากเมนูถาด แล้วแก้ไข คัดลอก บันทึก ปักหมุด หรือ OCR ซ้ำได้
- **ดูดสีจากหน้าจอ**: หน้าจอหยุดนิ่ง คลิกที่ไหนก็ได้เพื่อคัดลอกรหัสสี (ตั้งปุ่มลัดได้)
- **แคปเกมเต็มจอและจอ HDR ได้**: ใช้ Windows.Graphics.Capture เป็นค่าเริ่มต้น บนจอ HDR จะแปลงสีกลับเป็นปกติด้วยค่า "SDR content brightness" ของ Windows ภาพจึงไม่ซีด ถ้าใช้ไม่ได้จะกลับไปใช้แบบเดิม (GDI) เอง
- **หน้าแก้ไขภาพ**: แปรง, ปากกาไฮไลต์, เส้นตรง, ลูกศร, สี่เหลี่ยม, วงกลม/วงรี, ข้อความ, โมเสก, เบลอ, สปอตไลต์, ตัวเลขลำดับ, ยางลบ, ครอป, ปรับขนาด และปุ่มล้างทั้งหมด
  - ตัวเลือกสี RGB แบบเต็ม: ช่อง S/B, แถบ Hue, R/G/B, HEX, ความโปร่งใส และหลอดดูดสี
  - สีเส้นกับสีเติมแยกกัน
  - Undo/Redo ไม่จำกัด และซูมได้
- **2 ภาษา (ไทย / English)** เปลี่ยนได้ในหน้าตั้งค่าและเห็นผลทันที
- **ธีมสีทั้งโปรแกรม** (พื้นหลัง แผง ข้อความ ขอบ) แบบเดียวกับการเปลี่ยนธีมของโปรแกรมเขียนโค้ด:
  - ตามระบบ, มืด, สว่าง, เที่ยงคืน, ดำสนิท (เหมาะกับจอ OLED), ป่าสน, มอคค่า, องุ่น, กระดาษ, ซากุระ, ฟ้าใส
  - **กำหนดเอง**: เลือกสีพื้นหลังสีเดียว แล้วโปรแกรมจะสร้างสีแผง ข้อความ และขอบที่อ่านง่ายให้อัตโนมัติ (พื้นเข้มได้ตัวอักษรสว่าง พื้นอ่อนได้ตัวอักษรเข้ม)
  - ตัวติดตั้งจะใช้ภาษาที่เลือกตอนติดตั้งเป็นภาษาเริ่มต้นของแอป
- **สีหลักของโปรแกรม (accent)** แยกจากธีม: ค่าเริ่มต้นใช้สีหลักของแต่ละธีม หรือเลือกเองจากชุดสี (คราม, ม่วง, ชมพู, แดง, ส้ม, เหลืองอำพัน, เขียว, เขียวหัวเป็ด, ฟ้าน้ำทะเล, เทาเข้ม) หรือกำหนดสีเองด้วยตัวเลือกสีแบบเต็ม
  - ใช้กับปุ่ม, เครื่องมือที่เลือก, กรอบเลือกพื้นที่ตอนแคป, สวิตช์ และแถบเลื่อนทั้งโปรแกรม
  - สีของตัวอักษรบนปุ่มปรับให้อ่านง่ายเอง (สีอ่อนอย่างเหลืองอำพันจะใช้ตัวอักษรสีเข้ม)
- ฟอนต์ **IBM Plex Sans Thai** ฝังอยู่ในโปรแกรม เครื่องปลายทางไม่ต้องติดตั้งฟอนต์
- **บันทึก** ลงโฟลเดอร์ Downloads (ใช้ Known Folder ของ Windows) หรือโฟลเดอร์ที่เลือกเอง เป็น PNG หรือ JPG
  ตั้งชื่ออัตโนมัติ `Screenshot_yyyy-MM-dd_HH-mm-ss.png` และไม่เขียนทับไฟล์เดิม ถ้าชื่อซ้ำจะต่อท้ายเป็น ` (2)`, ` (3)` …

## วิธี build

### สิ่งที่ต้องมี

- Windows 10 หรือ 11 (x64)
- [.NET 10 SDK](https://dotnet.microsoft.com/download) ตรวจได้ด้วย `dotnet --list-sdks` (ต้องมี `10.0.x`)
- [Inno Setup 6 หรือ 7](https://jrsoftware.org/isdl.php) (ใช้สร้างตัวติดตั้ง)

### รัน/ดีบักระหว่างพัฒนา

```bash
dotnet run --project src/Freezia
```

หรือเปิด `Freezia.slnx` ด้วย Visual Studio 2026 / Rider แล้วกด Run
ถ้าจะ build ใหม่ขณะที่โปรแกรมรันอยู่ ให้ออกจากไอคอนในถาดก่อน หรือใช้คำสั่ง:

```bash
src/Freezia/bin/Debug/net10.0-windows/Freezia.exe --exit
```

### สร้างตัวติดตั้ง (คำสั่งเดียว)

```bash
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

สคริปต์จะ:
1. ตรวจว่ามี .NET 10 SDK
2. `dotnet publish` แบบ **self-contained ไฟล์เดียว** (win-x64) ไปที่ `artifacts\publish\Freezia.exe` เครื่องปลายทางจึงไม่ต้องลง .NET (ไฟล์ OCR ฝังอยู่ใน exe ด้วย)
3. ดาวน์โหลด Microsoft Visual C++ Redistributable (`vc_redist.x64.exe`) มาเก็บไว้ที่ `installer\redist\` ในครั้งแรก (ตรวจลายเซ็นดิจิทัลของ Microsoft ทุกครั้ง) เพื่อแนบไปกับตัวติดตั้ง
3. หา `ISCC.exe` ของ Inno Setup 6/7 แล้วสร้าง `artifacts\Freezia-Setup-<version>.exe`

ถ้าต้องการแค่ไฟล์ exe ไม่เอาตัวติดตั้ง ให้ใช้ `.\build.ps1 -SkipInstaller`
เลขเวอร์ชันอ่านจาก `<Version>` ใน `src/Freezia/Freezia.csproj`

---

### สร้างบน GitHub Actions (สำหรับปล่อยเวอร์ชันจริง)

workflow [`.github/workflows/release.yml`](.github/workflows/release.yml) build ตัวติดตั้งบนเครื่องของ GitHub ทุกครั้งที่ push tag เช่น `v1.0.1` (ต้องตรงกับ `<Version>` ใน `Freezia.csproj`) แล้วสร้างหน้า Release ให้
ถ้าตั้งค่า SignPath ไว้ (ตัวแปร `SIGNPATH_ORGANIZATION_ID` และ secret `SIGNPATH_API_TOKEN`) จะเซ็นดิจิทัลไฟล์ทั้งหมดก่อนแนบ เพื่อให้ Windows Smart App Control ยอมให้ติดตั้ง
ตั้งค่าใน SignPath ตามไฟล์ใน [`.signpath/artifact-configurations/`](.signpath/artifact-configurations)

## วิธีติดตั้ง

1. เปิด `Freezia-Setup-1.0.0.exe`
2. เลือกว่าจะติดตั้ง **ให้ทุกคน** (ต้องใช้สิทธิ์ผู้ดูแล → `C:\Program Files\Freezia`) หรือ **เฉพาะฉัน** (ไม่ต้องใช้สิทธิ์ผู้ดูแล → `%LocalAppData%\Programs\Freezia`)
3. เลือกโฟลเดอร์ติดตั้งเองได้
4. ตัวเลือกเพิ่มเติม (ไม่บังคับ ปิดไว้เป็นค่าเริ่มต้น): สร้างไอคอนบนเดสก์ท็อป และเปิด Freezia อัตโนมัติเมื่อเข้าสู่ Windows
5. ติดตั้งเวอร์ชันใหม่ทับเวอร์ชันเก่าได้เลย ตัวติดตั้งจะสั่งปิดโปรแกรมที่รันอยู่ให้เอง

### อัปเดตในแอป (ตั้งแต่เวอร์ชัน 1.0.1)

- Freezia ตรวจหน้า Releases บน GitHub ตอนเปิดโปรแกรมและทุก 6 ชั่วโมง ถ้ามีเวอร์ชันใหม่จะเด้งแจ้งเตือนมุมจอ
  และมีรายการ "อัปเดตเป็นเวอร์ชัน …" ในเมนูถาด
- กด **อัปเดตเลย** แล้วโปรแกรมจะดาวน์โหลด ตรวจ SHA-256 (และลายเซ็นดิจิทัล ถ้าเวอร์ชันที่ใช้อยู่มีลายเซ็น)
  ติดตั้งทับ แล้วเปิดตัวเองขึ้นมาใหม่ การตั้งค่าและประวัติยังอยู่ครบ
- ปิดการตรวจอัตโนมัติ หรือกด "ตรวจหาอัปเดตตอนนี้" ได้ที่หน้าตั้งค่า › ทั่วไป

### ปล่อยเวอร์ชันใหม่ (สำหรับผู้พัฒนา)

```bash
powershell -ExecutionPolicy Bypass -File .\release.ps1 1.0.1
```

สคริปต์จะแก้ `<Version>` ใน `Freezia.csproj`, commit, สร้าง tag `v1.0.1` แล้ว push จากนั้น GitHub Actions จะ build และสร้างหน้า Release
(รายการ "มีอะไรใหม่" มาจากหัวข้อ commit ตั้งแต่เวอร์ชันก่อนหน้า) ภายในประมาณ 10 นาที เครื่องที่ติดตั้ง Freezia ไว้จะเห็นการแจ้งเตือนอัปเดต

**ถอนการติดตั้ง** ทำได้ที่ Settings › Apps หรือ Control Panel ตัวถอนจะปิดโปรแกรมแล้วลบออกให้หมด:
- ไฟล์โปรแกรม, ทางลัดใน Start และเดสก์ท็อป
- ค่า "เปิดพร้อม Windows" (`HKCU\...\Run\Freezia`)
- การตั้งค่า `%AppData%\Freezia` และ log `%LocalAppData%\Freezia`
- ไฟล์ไลบรารีที่ .NET แตกไว้ใน `%TEMP%\.net\Freezia`

> หมายเหตุ: ไฟล์ภาพที่บันทึกไว้จะ **ไม่ถูกลบ**

## วิธีใช้

### โหมดแคปพื้นที่

| ปุ่ม | การทำงาน |
|---|---|
| ลากเมาส์ | เลือกพื้นที่ (กด `Shift` ค้าง = สี่เหลี่ยมจัตุรัส) |
| ลากในกรอบ / ลากที่จุดจับ | ย้าย / ปรับขนาดกรอบ |
| ลากนอกกรอบ | เลือกใหม่ |
| ลูกศร (`Shift` = 10 px, `Ctrl` = ปรับขนาด) | ขยับกรอบทีละพิกเซล |
| `Ctrl + C` หรือ `Enter` หรือดับเบิลคลิกในกรอบ | คัดลอก |
| `Ctrl + S` | บันทึก |
| `Ctrl + Shift + S` | บันทึกเป็น… |
| `E` | เปิดหน้าแก้ไข |
| `F` | แคปเต็มจอที่เมาส์อยู่ |
| `A` | แคปทุกจอ |
| คลิกเฉยๆ (ไม่ลาก) | เลือกทั้งหน้าต่างที่ไฮไลต์อยู่ (ถ้าเป็นเดสก์ท็อป = ทั้งจอ) |
| `Ctrl` ค้าง + ชี้ | ไฮไลต์ส่วนย่อยของหน้าต่าง เช่น ปุ่ม แผง ช่องข้อความ แล้วคลิกเพื่อเลือก |
| ล้อเมาส์ขณะไฮไลต์ | ขึ้น = ส่วนที่ใหญ่ขึ้น (ตัวแม่) / ลง = ส่วนที่เล็กลง |
| `P` | ปักหมุดภาพไว้บนจอ |
| `T` | ดึงข้อความ (OCR) แล้วคัดลอกให้ทันที |
| `Q` | อ่าน QR code / บาร์โค้ด แล้วคัดลอกข้อความ |
| `Esc` หรือคลิกขวา | ยกเลิก (คลิกขวาตอนมีกรอบ = ล้างกรอบ) |

เวลาคัดลอก ภาพจะอยู่บนคลิปบอร์ด 2 แบบพร้อมกัน:
- เป็นรูปภาพ สำหรับวางใน Paint, Word ฯลฯ
- เป็นไฟล์ชื่อ `Screenshot_yyyy-MM-dd_HH-mm-ss.png` แบบเดียวกับตอนบันทึก เวลาวางใน Explorer, Discord, LINE หรืออัปโหลดในเบราว์เซอร์ จะได้ชื่อไฟล์ที่บอกวันที่และเวลา (ไฟล์ชั่วคราวเก็บใน `%LocalAppData%\Freezia\clipboard` และลบเองหลัง 1 วัน)

หลังคัดลอกหรือบันทึก จะมีแจ้งเตือนเล็กๆ ที่มุมขวาล่างของจอ คลิกที่แจ้งเตือนเพื่อเปิดโฟลเดอร์ที่ไฟล์อยู่

### ภาพที่ปักหมุดไว้บนจอ

| การกระทำ | ผล |
|---|---|
| ลาก | ย้าย |
| ล้อเมาส์ | ซูม 10–400% (รอบตำแหน่งเมาส์) |
| `Ctrl` + ล้อเมาส์ | ความโปร่งใส 20–100% |
| ดับเบิลคลิก หรือ `Esc` | ปิด |
| คลิกขวา | คัดลอก / บันทึก / แก้ไข / ขนาดจริง 100% / ปิด |

### ประวัติการแคปและดูดสีจากหน้าจอ

- **ประวัติ**: เมนูถาด › ประวัติการแคป ดับเบิลคลิกภาพ = เปิดแก้ไข คลิกขวา = คัดลอก / บันทึกเป็น / ปักหมุด / OCR / แสดงไฟล์ / ลบ
  - เก็บทุกภาพที่คัดลอก บันทึก แก้ไข ปักหมุด หรือ OCR (ภาพเดิมซ้ำติดกันจะไม่เก็บซ้ำ) ไว้ที่ `%LocalAppData%\Freezia\history`
  - ตั้งจำนวน หรือปิดได้ที่หน้าตั้งค่า › ทั่วไป (ปิดแล้วจะลบประวัติทั้งหมด) และตัวถอนการติดตั้งจะลบให้
- **ดูดสี**: เมนูถาด › ดูดสีจากหน้าจอ หรือปุ่มลัดที่ตั้งไว้ คลิก = คัดลอก `#HEX`, `Shift` + คลิก = คัดลอก `rgb(…)`, `Esc` = ยกเลิก สีที่ดูดจะไปอยู่ใน "สีล่าสุด" ของหน้าแก้ไขด้วย

### OCR และ QR code

- ผลลัพธ์จะถูกคัดลอกให้ทันที และเปิดหน้าต่างเล็กให้แก้ข้อความก่อนคัดลอกซ้ำได้ (เลือกบางส่วนแล้วคัดลอกได้)
- ถ้า QR เป็นลิงก์ จะมีปุ่ม "เปิดลิงก์" โปรแกรมไม่เชื่อมต่อเอง จะเปิดเบราว์เซอร์ก็ต่อเมื่อคุณกดเท่านั้น
- ในหน้าแก้ไขมีปุ่ม ปักหมุด / OCR / QR เหมือนกัน (ใช้ภาพที่แก้ไขแล้ว)
- OCR ครั้งแรกจะแตกไฟล์ภาษา (ประมาณ 30 MB) ไปไว้ที่ `%LocalAppData%\Freezia\ocr` ครั้งต่อไปจะเร็วขึ้น

### หน้าแก้ไขภาพ

| ปุ่ม | เครื่องมือ / คำสั่ง |
|---|---|
| `V` | เลือก/ย้าย (ดับเบิลคลิกข้อความเพื่อแก้ไข, ลูกศรเพื่อขยับ, เส้น/ลูกศรที่เลือกมีจุดจับที่ปลายทั้งสองข้าง) |
| `B` / `H` | แปรง / ปากกาไฮไลต์ |
| `L` / `A` | เส้นตรง / ลูกศร (`Shift` = ล็อกมุมทีละ 45°) วาดเสร็จแล้วลากจุดจับที่ปลายเพื่อเปลี่ยนความยาวหรือทิศทางได้ |
| `R` / `O` | สี่เหลี่ยม / วงกลม-วงรี (`Shift` = จัตุรัส / วงกลมพอดี) |
| `T` | ข้อความ (`Ctrl + Enter` หรือ `Esc` หรือคลิกที่อื่น = เสร็จ) ลากข้อความที่มีอยู่เพื่อย้าย คลิกเฉยๆ เพื่อแก้ไข |
| `M` | โมเสกปิดข้อมูล (ความหนา = ขนาดบล็อก) |
| `N` | ตัวเลขลำดับ (เพิ่มเลขเองอัตโนมัติ) |
| `C` | ครอป: ลากกรอบ แล้วกด `Enter` (หรือปุ่ม "ครอป") • สิ่งที่วาดยังแก้ไขได้และขยับตามภาพ |
| ปุ่มปรับขนาด (ถัดจากครอป) | กำหนดขนาดเป็นพิกเซลหรือ % ล็อกสัดส่วนได้ (สิ่งที่วาดจะถูกรวมเข้ากับภาพ กด Undo ย้อนได้) |
| `U` | เบลอ: ปิดข้อมูลแบบนุ่ม แทนที่พิกเซลจริง ความแรงปรับที่แถบ "ความเบลอ" |
| `S` | สปอตไลต์: พื้นที่ที่ลากยังสว่าง ส่วนอื่นมืดลง (หลายจุดรวมเป็นชั้นมืดเดียว) • กด `Shift` ตอนเริ่มลาก = วงรี |
| `E` | ยางลบ: ลากผ่านเพื่อลบเฉพาะสิ่งที่วาด (ภาพหน้าจอไม่ถูกลบ) ขนาดปรับที่แถบ "ขนาดยางลบ" |
| `Ctrl + Shift + Delete` | ล้างสิ่งที่วาดทั้งหมด (กด `Ctrl + Z` ย้อนได้) |
| `Ctrl + Z` / `Ctrl + Y` (หรือ `Ctrl + Shift + Z`) | เลิกทำ / ทำซ้ำ |
| `Delete` | ลบวัตถุที่เลือก |
| `Ctrl + C` / `Ctrl + S` / `Ctrl + Shift + S` | คัดลอก / บันทึก / บันทึกเป็น… |
| `Ctrl + ล้อเมาส์`, `Ctrl + +` / `Ctrl + -` | ซูม |
| ล้อเมาส์ / `Shift + ล้อเมาส์` | เลื่อนภาพแนวตั้ง / แนวนอน (รองรับการเลื่อนแนวนอนของทัชแพดและล้อเอียงด้วย) |
| `Ctrl + 0` / `Ctrl + 1` | พอดีหน้าต่าง / 100% (1 พิกเซลภาพ = 1 พิกเซลจอ) |

**สี**
- ปุ่มสีเส้นอยู่ซ้ายสุด ถัดไปเป็นปุ่มสีเติม คลิกเพื่อเปิดตัวเลือกสี
- สีสำเร็จรูป สีที่บันทึกไว้ และสีล่าสุด จะใช้กับปุ่มที่ไฮไลต์อยู่ (เส้นหรือเติม)
- **สีที่บันทึกไว้**: กดปุ่ม `+` บนแถบเครื่องมือ (หรือปุ่ม `+` ในหน้าต่างเลือกสี) เพื่อเก็บสีไว้ใช้ครั้งต่อไป ได้สูงสุด 11 สี และคลิกขวาที่สีเพื่อลบ
- **หลอดดูดสี**: เปิดหน้าต่างเลือกสี กดรูปหลอดดูด แล้วคลิกบนภาพ ระหว่างนี้แถบล่างจะแสดงรหัสสีใต้เมาส์
- ถ้าเลือกวัตถุไว้แล้วเปลี่ยนสี/ความหนา/การเติมสี วัตถุนั้นจะเปลี่ยนทันทีและกด Undo ย้อนได้
- สีที่บันทึกไว้และสีที่ใช้ล่าสุด 8 สี จำไว้ใน `settings.json`

ภาพที่ส่งออกจะมีขนาดพิกเซลเท่ากับตอนแคปทุกประการ ไม่ว่าจะซูมอยู่ที่เท่าไร
โมเสกจะแทนที่พิกเซลจริงในไฟล์ จึงกู้ข้อความใต้โมเสกกลับมาไม่ได้

|---|---|
| การตั้งค่า | `%AppData%\Freezia\settings.json` (ไฟล์เสียหรือหายจะใช้ค่าเริ่มต้นแทน) |
| Log | `%LocalAppData%\Freezia\logs\` (เก็บ 14 วัน) |

## ข้อจำกัดที่ทราบ

- **OCR ต้องใช้ Microsoft Visual C++ Redistributable (x64)**: ตัวติดตั้งจะติดตั้งให้เฉพาะเครื่องที่ยังไม่มี (อาจถามสิทธิ์ผู้ดูแล) ถ้าใช้แบบพกพาบนเครื่องที่ไม่มี runtime นี้ OCR จะแจ้งให้ติดตั้งก่อน ส่วนฟีเจอร์อื่นยังใช้ได้ตามปกติ
- **OCR**: ความแม่นยำขึ้นกับคุณภาพภาพ ตัวอักษรเล็กมากหรือฟอนต์ตกแต่งอาจอ่านผิด
- **เลือกส่วนย่อยด้วย Ctrl**: ขึ้นกับว่าแอปนั้นรองรับ UI Automation แค่ไหน บางแอป (เช่น เกม หรือหน้าต่างที่วาดเอง) จะเลือกได้แค่ทั้งหน้าต่าง

- **Snipping Tool ของ Windows 11**: Freezia ดักปุ่ม PrintScreen ไว้ไม่ให้ Snipping Tool เด้ง แต่ถ้ายังเด้งอยู่ ให้ปิดที่
  Settings › Accessibility › Keyboard › *Use the Print screen key to open screen capture*
- **หน้าต่างที่รันแบบ Administrator**: ถ้าหน้าต่างที่โฟกัสอยู่รันด้วยสิทธิ์ผู้ดูแล Windows จะไม่ส่งปุ่มลัดมาให้ Freezia (ข้อจำกัดด้านความปลอดภัยของ Windows)
  วิธีแก้คือคลิกที่หน้าต่างอื่นก่อน หรือแคปจากเมนูในถาดระบบ
- **วิดีโอที่มี DRM** (Netflix ฯลฯ) จะออกมาเป็นสีดำเสมอ Windows ตั้งใจบล็อกไว้ทุกวิธีการจับภาพ
- **วิธีจับภาพ "อัตโนมัติ"** ใช้ Windows.Graphics.Capture (Windows 10 1903 ขึ้นไป):
  - แคปเกมเต็มจอและจอ HDR ได้ถูกต้อง
  - บน Windows 10 อาจเห็นขอบสีเหลืองกะพริบรอบจอตอนแคป ส่วน Windows 11 ซ่อนขอบนี้ได้
  - ถ้าเครื่องใช้ไม่ได้ จะกลับไปใช้แบบเดิม (GDI) ให้เอง และเลือกบังคับใช้แบบเดิมได้ที่หน้าตั้งค่า › ทั่วไป › วิธีจับภาพ
- **จอ HDR**: แปลงสีด้วยค่า SDR content brightness ส่วนที่สว่างกว่าสีขาวของ SDR จะถูกตัดที่สีขาว (ภาพ PNG/JPG เป็น SDR)
- **แคปทุกจอ** เมื่อจอมีขนาดหรือตำแหน่งไม่เท่ากัน พื้นที่ว่างที่ไม่มีจอจะเป็นสีดำ
- **ไอคอนเก่ายังโผล่ที่ taskbar หลังอัปเดต**: เพราะ Windows เก็บแคชไอคอนไว้ ตัวติดตั้งสั่งรีเฟรชให้แล้ว ถ้ายังไม่เปลี่ยน ให้ปิด/เปิด Explorer หรือรีสตาร์ตเครื่อง
- **ตัวติดตั้งไม่ได้เซ็นดิจิทัล**:
  - Windows SmartScreen อาจเตือน ให้กด *More info › Run anyway*
  - โปรแกรมแอนตี้ไวรัสบางตัวอาจจับตามองเพราะมีการใช้ low-level keyboard hook (ใช้ดักปุ่ม PrintScreen)
  - การเซ็นโค้ดทำได้แต่มีค่าใช้จ่าย
- **ปุ่มลัดที่ซ้ำกับโปรแกรมอื่น**: Freezia จะดักปุ่มก่อน ส่วนปุ่มเดี่ยวที่ใช้พิมพ์ (ตัวอักษร, ตัวเลข, Space ฯลฯ) ระบบจะไม่ให้ตั้งถ้าไม่มี Ctrl/Shift/Alt/Win ร่วมด้วย
- **"เปิดพร้อม Windows"** เป็นค่าของผู้ใช้แต่ละคน (`HKCU`) แม้จะติดตั้งแบบทุกคน
- ไฟล์ exe เป็นแบบไฟล์เดียว ตอนเปิดครั้งแรก .NET จะแตกไลบรารีของ WPF ไว้ที่ `%TEMP%\.net\Freezia` ซึ่งตัวถอนการติดตั้งจะลบให้
- Inno Setup ใช้ฟรีสำหรับงานที่ไม่ใช่เชิงพาณิชย์ ถ้าจะขายโปรแกรมต้องซื้อ license ของ Inno Setup

## เช็กลิสต์สำหรับทดสอบเอง

**อัปเดต**
- [ ] ติดตั้งเวอร์ชันเก่า แล้วปล่อยเวอร์ชันใหม่: แจ้งเตือนเด้งภายใน ~20 วินาทีหลังเปิดโปรแกรม และมีรายการในเมนูถาด
- [ ] กดอัปเดต: ดาวน์โหลด ติดตั้ง แล้ว Freezia เปิดขึ้นมาใหม่เป็นเวอร์ชันใหม่ (ลองทั้งแบบติดตั้ง "เฉพาะฉัน" และ "ทุกคน" ซึ่งจะถาม UAC)
- [ ] ปิด "ตรวจหาอัปเดตอัตโนมัติ": ไม่มีการเชื่อมต่อเลย

**ปุ่มลัดและการแคป**
- [ ] `PrintScreen` เข้าโหมดแคปพื้นที่ และ Snipping Tool ไม่เด้ง
- [ ] `Ctrl + PrintScreen` ได้ภาพเต็มจอของจอที่เมาส์อยู่ (ลองทั้งจอหลักและจอรอง)
- [ ] `Ctrl + Shift + PrintScreen` ได้ภาพทุกจอรวมกัน
- [ ] ตอนโฟกัสอยู่ที่หน้าต่างที่ "Run as administrator" ปุ่มลัดไม่ทำงาน (เป็นข้อจำกัดของ Windows) แต่เมนูในถาดยังใช้ได้
- [ ] เปลี่ยนปุ่มลัดในหน้าตั้งค่า: ลองตั้งซ้ำกัน (ต้องขึ้นข้อความเตือน), ลอง `Win + Shift + S`, ลอง `Alt + PrintScreen`

**หลายจอ / DPI**
- [ ] 2 จอที่ scaling ต่างกัน (เช่น 100% + 150%): overlay คลุมพอดีทุกจอ, กรอบเลือกตรงกับเมาส์, ขนาดที่แสดงตรงกับไฟล์ที่ได้
- [ ] จอรองอยู่ทางซ้ายหรือด้านบนของจอหลัก (พิกัดติดลบ)
- [ ] จอ 4K
- [ ] ลากเลือกข้ามจอ
- [ ] คลิกเดียวเลือกทั้งหน้าต่าง, กด Ctrl เพื่อเลือกปุ่ม/แผง, หมุนล้อเมาส์เพื่อขยับระดับ
- [ ] `P` ปักหมุด: ภาพตรงตำแหน่งเดิม คมชัดที่ 100%, ซูม ปรับความโปร่งใส ย้าย ปิดได้
- [ ] `T` OCR: อ่านภาษาไทยและอังกฤษในหน้าเว็บ/เอกสาร ได้ข้อความในคลิปบอร์ด
- [ ] `Q` QR: อ่าน QR จากหน้าจอ ลิงก์มีปุ่มเปิดลิงก์
- [ ] ประวัติ: แคปหลายครั้งแล้วเปิดหน้าต่างประวัติ, จำนวนไม่เกินที่ตั้ง, ปิดประวัติแล้วภาพหายหมด
- [ ] ดูดสีจากหน้าจอ (หลายจอ / DPI ต่างกัน): รหัสสีตรงกับพิกเซลที่คลิก
- [ ] เกมแบบเต็มจอ และจอที่เปิด HDR: ภาพไม่ดำ สีไม่ซีด (เทียบกับวิธี "แบบเดิม" ในหน้าตั้งค่า)
- [ ] Windows 10: สังเกตขอบเหลืองตอนแคป ถ้ารบกวนให้เปลี่ยนเป็น "แบบเดิม"
- [ ] เครื่องที่ไม่มี VC++ runtime: ติดตั้งแล้ว OCR ใช้ได้ทันที

**คลิปบอร์ดและการบันทึก**
- [ ] วางภาพลงใน Paint, Word, LINE, Discord และเบราว์เซอร์ (เช่น Gmail)
- [ ] คัดลอกแล้ววางใน Explorer / Discord: ได้ไฟล์ชื่อ `Screenshot_วันที่_เวลา.png`
- [ ] บันทึกไปโฟลเดอร์ที่ชื่อมีเว้นวรรคและภาษาไทย
- [ ] ย้ายโฟลเดอร์ Downloads ไปไดรฟ์อื่น (Properties › Location) แล้วบันทึกยังไปถูกที่
- [ ] บันทึกหลายครั้งในวินาทีเดียวกัน: ได้ ` (2)`, ` (3)` และไม่เขียนทับ
- [ ] JPG: ภาพถูกต้อง ไม่มีพื้นหลังดำ

**หน้าแก้ไข**
- [ ] ยางลบลบเฉพาะส่วนที่ลากผ่าน ภาพหน้าจอด้านล่างยังอยู่, ย้ายวัตถุที่ถูกลบบางส่วนแล้วรอยลบย้ายตามไปด้วย, Undo ได้
- [ ] ปุ่มล้างทั้งหมดลบทุกอย่างที่วาด และ Undo กลับมาได้ครบ
- [ ] ครอปหลังจากวาดแล้ว: สิ่งที่วาดอยู่ตำแหน่งเดิมบนภาพ, Undo กลับเป็นภาพเต็ม
- [ ] ปรับขนาด 50% / กำหนดพิกเซลเอง: ไฟล์ที่บันทึกได้ขนาดตามที่ตั้ง
- [ ] เบลอและสปอตไลต์หลายจุด: ส่งออกแล้วข้อมูลใต้เบลออ่านไม่ออก
- [ ] ทุกเครื่องมือวาดได้, Shift ล็อกรูปทรงได้, ย้าย/ลบ/เปลี่ยนสีวัตถุเดิมได้ และ Undo/Redo ได้ทุกขั้น
- [ ] ตัวเลือกสี: ลากในช่องสีหรือพิมพ์ค่าแล้วหน้าต่างไม่หายไป, ทุกส่วนอัปเดตตามกันแบบ real-time, หลอดดูดสีดึงสีจากภาพได้, กด "เดิม" แล้วกลับเป็นสีเดิม
- [ ] กด `+` เพื่อบันทึกสี ปิดแล้วเปิดโปรแกรมใหม่สียังอยู่ และคลิกขวาเพื่อลบได้
- [ ] ซูมเข้าแล้วกด `Shift + ล้อเมาส์` เพื่อเลื่อนแนวนอน
- [ ] กรอบแดงเติมเหลืองโปร่งใสได้
- [ ] ซูม 25% / 100% / 400% แล้วบันทึก: ไฟล์ขนาดเท่าตอนแคปและไม่เบลอ

**ภาษาและธีม**
- [ ] สลับ ไทย / English ในหน้าตั้งค่า: หน้าตั้งค่า หน้าแก้ไขที่เปิดอยู่ และเมนูถาดเปลี่ยนภาษาทันที
- [ ] ลองทุกธีม: พื้นหลัง แผง ข้อความ และแถบหัวหน้าต่างเปลี่ยนตาม และถ้าเลือก "ตามระบบ" แล้วเปลี่ยนโหมดใน Windows แอปเปลี่ยนตามทันที
- [ ] ธีม "กำหนดเอง": ลากเลือกสีพื้นหลังแล้วเห็นผลทันที ลองทั้งสีเข้มและสีอ่อน ตัวอักษรต้องอ่านง่ายเสมอ
- [ ] เลือกสีหลักแต่ละชุด และกำหนดสีเอง: ปุ่ม, เครื่องมือที่เลือก, กรอบเลือกตอนแคปเปลี่ยนสีตาม ทั้งในธีมมืดและสว่าง
- [ ] กด "ยกเลิก" ในหน้าตั้งค่า: ภาษา ธีม และสีหลักกลับเป็นค่าเดิม

**ตัวติดตั้ง**
- [ ] ติดตั้งแบบ "เฉพาะฉัน" ลงโฟลเดอร์ที่เลือกเอง และแบบ "ทุกคน" ลง Program Files

- [ ] ถอนการติดตั้ง: ไม่เหลือไฟล์โปรแกรม, ทางลัด, ค่า Run, `%AppData%\Freezia`, `%LocalAppData%\Freezia`
- [ ] ออกจากเมนูถาดแล้วไม่มีไอคอนค้างในถาด
